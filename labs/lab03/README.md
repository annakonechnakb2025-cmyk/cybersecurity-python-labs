## 2. Структура проєкту
* `schema.sql` — схема таблиць SQLite з обмеженнями `CHECK` та `FOREIGN KEY`.
* `database.py` — модуль підключення до бази даних (`data/lab3.sqlite3`) та її ініціалізації.
* `seed.json` — початкові навчальні дані для Варіанта 13.
* `seed.py` — скрипт транзакційного заповнення бази даних із JSON.
* `repository.py` — шар доступу до даних (параметризовані SQL-запити, `JOIN`, пагінація).
* `schemas.py` — моделі валідації вхідних і вихідних даних на базі Pydantic 2.
* `main.py` — головний файл FastAPI-застосунку з життєвим циклом (`lifespan`).
* `routers/` — папка з модулями маршрутів для категорій (`categories.py`) та записів (`records.py`).

## 3. Інструкція з відтворення та запуску (після клонування репозиторію)

### Крок 1. Встановлення залежностей
Переконайтеся, що ви перебуваєте в корінному каталозі репозиторію та активували ваше віртуальне середовище. Встановіть необхідні пакети:
```bash
pip install -r requirements.txt
```

### Крок 2. Початкове заповнення бази даних
Виконайте скрипт заповнення бази навчальними даними з seed.json (таблиця створиться автоматично):
```bash
python -m labs.lab03.seed
```

### Крок 3. Запуск FastAPI сервером
Запустіть застосунок за допомогою uvicorn в режимі розробки (--reload):
```bash
uvicorn labs.lab03.main:app --reload --host 127.0.0.1 --port 8000
```

### Крок 4. Інтерактивна документація
Відкрийте в браузері автоматично згенеровану документацію Swagger UI:
http://127.0.0.1:8000/docs

## 4. Приклади основних запитів (cURL)

Перевірка доступності API:
```bash
curl.exe -i "http://127.0.0.1:8000/ping"
```

Отримання інформації про студента:
```bash
curl.exe -i "http://127.0.0.1:8000/student"
```

Отримання списку всіх категорій:
```bash
curl.exe -i "http://127.0.0.1:8000/categories"
```

Отримання списку записів із фільтрами та пагінацією:
```bash
curl.exe -i "http://127.0.0.1:8000/records?category_id=1&status=new&limit=5&offset=0"
```
