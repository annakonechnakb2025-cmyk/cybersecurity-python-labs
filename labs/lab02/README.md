## 4. Вхідні файли

Програма приймає на вхід **директорію**, яка передається через параметр `--scan-dir`.

Після цього виконується рекурсивне сканування файлів у цій директорії та всіх її підкаталогах.

Для варіанта №13 використовуються такі фактичні тестові файли:

```text
labs/lab02/data/data_v13/scan/exports/export.json
labs/lab02/data/data_v13/scan/logs/app.log
labs/lab02/data/data_v13/scan/notes/users.log
labs/lab02/data/data_v13/scan/clean.log
```

## 5. Приклади запуску `demo` та `analyze`

### 5.1. Запуск демонстрації

Команда для запуску демонстрації Завдання 1:

```bash
python -m labs.lab02.main demo
```

Демонстрація показує роботу користувача, облікового запису, перевірку пароля, валідацію email, права адміністратора, вихід із системи та журнал аудиту.

### 5.2. Повне сканування тестових даних

```bash
python -m labs.lab02.main analyze --scan-dir labs/lab02/data/data_v13/scan --patterns all --mask --out-json labs/lab02/data/data_v13/pii_scan_summary.json
```

### 5.3. Пошук тільки email-адрес

```bash
python -m labs.lab02.main analyze --scan-dir labs/lab02/data/data_v13/scan --patterns emails --mask --out-json labs/lab02/data/data_v13/pii_scan_summary.json
```

### 5.4. Пошук номерів банківських карток

```bash
python -m labs.lab02.main analyze --scan-dir labs/lab02/data/data_v13/scan --patterns cards --mask --out-json labs/lab02/data/data_v13/pii_scan_summary.json
```

### 5.5. Сканування без маскування

```bash
python -m labs.lab02.main analyze --scan-dir labs/lab02/data/data_v13/scan --patterns all --out-json labs/lab02/data/data_v13/pii_scan_summary.json
```

## 6. Опис параметрів CLI

### Команда `demo`

```bash
python -m labs.lab02.main demo
```

Запускає демонстрацію функціональності Завдання 1.

### Команда `analyze`

```bash
python -m labs.lab02.main analyze [параметри]
```

Запускає рекурсивне сканування заданої директорії.

| Параметр     | Обов'язковий | Опис                                                                        |
| ------------ | ------------ | --------------------------------------------------------------------------- |
| `--scan-dir` | Так          | Шлях до директорії, яку необхідно просканувати                              |
| `--patterns` | Ні           | Тип даних для пошуку: `all`, `cards` або `emails`. За замовчуванням — `all` |
| `--mask`     | Ні           | Вмикає маскування виявлених конфіденційних даних                            |
| `--out-json` | Так          | Шлях до JSON-файлу, у який буде збережено звіт                              |

Під час сканування програма шукає email-адреси, номери банківських карток, номери телефонів та IPv4-адреси.

## 7. Поведінка при помилках

* Якщо під час запуску не вказати обов'язковий параметр `--scan-dir` або `--out-json`, `argparse` повідомить про помилку та покаже довідку щодо використання команди.
* Якщо передано неприпустиме значення параметра `--patterns`, `argparse` повідомить про помилку та покаже допустимі значення: `all`, `cards`, `emails`.
* Якщо окремий файл неможливо прочитати через `UnicodeDecodeError` або `OSError`, цей файл пропускається, а сканування інших файлів продовжується.
* Якщо виявлено конфіденційні дані, вони відображаються у звіті. При використанні параметра `--mask` знайдені значення маскуються.
* Якщо конфіденційні дані не знайдено, у консоль виводиться повідомлення про відсутність знайдених даних.
* JSON-звіт зберігається за шляхом, який вказано через `--out-json`.

## 8. Результат роботи

Після завершення сканування створюється JSON-звіт із такою основною інформацією:

* кількість просканованих файлів;
* кількість знайдених елементів кожного типу;
* список знайдених збігів;
* назва файлу та номер рядка, у якому було знайдено дані;
* замасковані значення, якщо було використано параметр `--mask`.

Приклад запуску:

```bash
python -m labs.lab02.main analyze --scan-dir labs/lab02/data/data_v13/scan --patterns all --mask --out-json labs/lab02/data/data_v13/pii_scan_summary.json
```

Результатом буде створення файлу:

```text
labs/lab02/data/data_v13/pii_scan_summary.json
```
